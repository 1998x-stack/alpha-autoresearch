## 问题：量化因子研究的本质是什么？

— 找到一个数学公式，输入价格和成交量，输出一个排序。排序越准，赚钱概率越高。

— 传统做法：研究员手工调参数，跑回测，看 IC。慢，且非常依赖经验。

— AI 做法：让 agent 自己写公式、自己评估、自己决定保留还是丢弃。**无限循环。**

但这里有个坑：

量化因子不能只看一个指标。

— 只看 IC？可能出现高 IC 但天天换仓（交易成本吃掉所有收益）。

— 只看换手率？可能稳定但毫无预测力。

— 只看稳定性？可能稳定地预测错误方向。

**这是个多目标优化问题。**

---

## 方案：三个指标，一个帕累托前沿

我从第一性原理出发，选了三个指标：

| 指标 | 衡量什么 | 公式 |
|------|---------|------|
| **RankIC** | 预测能力强不强 | `Spearman(因子值, 未来收益)` |
| **IC IR** | 预测稳不稳定 | `mean(IC) / std(IC)` |
| **换手稳定性** | 交易成本高不高 | `1 - mean(\|排名变化\|)` |

三个指标构成一个**帕累托前沿**：

> 一个因子在某个指标上更好，必然在另一个指标上更差。优化目标不是单点，而是推进整个前沿面。

这比单目标优化高明在：**agent 不会陷入"刷 IC 但牺牲换手"的作弊陷阱。**

## 实战：30 轮实验，38 个因子，0 次崩溃

我用 **495 只 A 股、5 年日线数据**（2020-2025）跑了一轮。

系统只有三个文件：

```
factors.py     ← agent 编辑（写因子）
prepare.py     ← 只读（评估引擎）
program.md     ← agent 指令（迭代原则）
```

Agent 每轮写 1-2 个因子，系统自动评估并更新帕累托前沿。

— 平均 **3 秒**一个实验。

— 30 轮跑完只用了 **4 分钟**。

— 一夜 8 小时能跑 **500 次实验**。

### 最好的几个因子

▶ **hl_range（价格区间因子）**：`(high - low) / close`

IC = **0.058**，是所有因子中最强的。A 股的日内振幅信息远比趋势信息有预测力。

▶ **ts_rank_vol（成交量时序排名）**：`-ts_rank(volume, 5)`

IR = **0.49**，最稳定的信号。对每只股票做时间序列上的成交量百分位排名，捕捉量能变化。

▶ **vwap_diff（VWAP 偏离）**：`close - vwap`

换手稳定性 = **0.991**，几乎零交易成本。中等 IC，但可以大规模部署。

## 几个反直觉的发现

✗ **动量因子在 A 股是反向指标。** 所有动量因子 IC 全为负数（范围 -0.02 到 -0.06）。A 股是反转市，不是动量市。这和美股完全相反。

✓ **反转因子换手极低。** reversal_5d 和 reversal_10d 的换手稳定性都在 0.97 以上，意味着你不需要天天调仓也能吃到反转收益。

✓ **VWAP 是性价比之王。** VWAP 偏离因子的换手稳定性接近 1.0（几乎零换手），IC 也不算差，适合大规模资金。

✓ **简单的量价相关性完全没用。** `corr(close, volume, 10)` 的 IC 不到 0.004。A 股的价量关系比想象中复杂。

## 代码：怎么写一个因子

```python
from prepare import Factor, ops

class Factor001(Factor):
    name = "momentum_5d"

    def compute(self, df):
        m = df.set_index(["datetime", "symbol"])
        val = ops.cs_rank(m["close"] - ops.delay(m["close"], 5))
        return Factor.as_cs_series(df, val)
```

3 行核心逻辑。自动发现，自动评估，自动归档。

Agent 有 **12 个内置算子**可用：`cs_rank`、`ts_rank`、`rolling_corr`、`delta`、`delay`、`decay_linear` 等。

**16 个数据列**：价格、成交量、VWAP、收益率、ADV（5-180 日不等）。
